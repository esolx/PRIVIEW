=====================================
목적외사용(purpose_gate) 모듈 실행 안내
=====================================

가명정보 활용 계획서(PDF)와 데이터셋(CSV)을 받아,
선택한 목적에 적합한지 판정하고 가명처리 대상 컬럼을 골라내는 모듈입니다.


[사전 준비]

1. 자바(JDK) 설치
   - 형태소 분석(KoNLPy)에 자바가 필요합니다.
   - 터미널에서 java -version 으로 설치 여부 확인
   - 없으면 Temurin JDK 17 (https://adoptium.net) 설치
   - 설치 후에도 인식이 안 되면 JAVA_HOME 환경변수 설정 필요

2. 폴더 위치 주의
   - OneDrive 안이나 한글/공백이 포함된 경로는 자바 오류를 일으킵니다.
   - C:\PBL\purpose_gate 처럼 영문 경로에 두는 것을 권장합니다.


[설치]

1. 가상환경 생성 및 활성화 (처음 한 번)
   py -m venv venv
   .\venv\Scripts\activate

2. 라이브러리 설치
   pip install konlpy pdfplumber pandas openai


[API 키 등록 - LLM 기능용]

LLM(GPT)으로 금지 키워드의 맥락, 의도를 판단합니다.
OpenAI API 키를 환경변수에 등록하세요.

   $env:OPENAI_API_KEY = "본인_API_키"

주의:
- 이 등록은 해당 터미널 창에서만 유효합니다. 창을 닫으면 다시 등록해야 합니다.
- 키를 등록한 바로 그 터미널에서 코드를 실행하세요.
- 등록 확인: 환경변수의 설정 여부만 확인 (키 값 출력 금지)
- API 키 없이 실행해도 코드는 정상 작동합니다 (규칙 기반으로만 판정).
- 키는 코드에 직접 넣지 말고 반드시 환경변수로 관리하세요 (보안).


[실행]

   py test.py        (테스트 예시 실행)
   py main.py        (직접 사용 시)

사용 예시:
   from main import run
   결과 = run("과학적연구", "계획서.pdf", "데이터.csv")


[목적 값]

목적은 아래 세 가지 중 하나를 넘깁니다 (띄어쓰기 없이):
   "통계작성" / "과학적연구" / "공익적기록보존"


[반환 형태]

{
  "판정": "통과" 또는 "반려",
  "반려사유": [...],
  "미충족항목": [...],
  "위험키워드": {...},
  "가명처리대상": [...]     (통과 시 목적과 상관없는 민감 컬럼, 반려 시 빈 목록)
}


[파일 구성]

[판정]
  document_reader.py  - PDF 텍스트 추출
  preprocess.py       - 텍스트 정리, 유효성 검증, 부정문 판별
  rules.py            - 규칙표 (필요어/금지어, 전역 금지 키워드)
  keyword_match.py    - 1단계 키워드 매칭
  llm_check.py        - 2단계 LLM 맥락, 의도 판단
  purpose_gate.py     - 최종 통과/반려 판정
[데이터 컬럼]
  data_reader.py      - CSV 읽기
  sensitive_columns.py- 민감 컬럼 키워드
  column_check.py     - 가명처리 대상 선별
[진입점]
  main.py             - 판정 + 대상 선별 전체 실행
[테스트]
  test.py             - 실행 예시


[판정 구조]

0. 목적 선택 확인 + 문서 유효성 검증
1. 키워드 매칭 (규칙 기반): 필요어/금지어를 형태소 매칭으로 검사
2. LLM 확인: 걸린 금지어가 부정문이거나 연구, 통계의 주제인지 판단하여 보정
   -> 하나라도 걸리면 반려, 걸린 항목을 모두 반환
3. 통과 시 목적과 상관없는 민감 컬럼을 가명처리 대상으로 선별


[참고]

- 스캔 이미지 PDF는 텍스트 추출이 안 됩니다 (워드→PDF로 저장한 문서 사용).
- 민감 컬럼 및 목적별 허용 기준은 적용 환경에 따라 검토가 필요합니다.
